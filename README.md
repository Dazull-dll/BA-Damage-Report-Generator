# Blue Archive Damage Report Generator
A website designed to generate custom damage report images.

## Features
- **Student Selection:** Choose and switch between different students.
- **Custom Names:** Update and personalize student names.
- **Chart Title:** Customize the title on the graph.
- **Real-Time Graph Update:** Charts automatically recalculate and redraw with every new value entered.
- **Image Export:** Download the generated graph directly as an image.
